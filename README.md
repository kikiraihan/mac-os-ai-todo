# AI Todo (nama kerja)

Todo list yang dikelola lewat **chat dengan AI**: ketik *"besok jam 9 ingetin telpon bengkel"* dan AI
yang menambah todo serta pengingatnya. Terdiri dari:

- **Aplikasi menu bar macOS**: daftar todo hari ini, chat cepat (hotkey), notifikasi lokal.
- **Server sendiri** (Go, satu binary): menyimpan todo & pengingat, menjalankan AI, mengirim notifikasi.
- **PWA**: dipakai dari HP, tablet, atau PC lain, bisa di-install dan menerima notifikasi.

Konsepnya mengikuti [PasteLAN](https://github.com/kikiraihan/mac-os-PasteLAN).
